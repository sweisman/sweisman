# Scott Weisman

**Senior Software Engineer | Backend Systems, Data Pipelines, Cloud Infrastructure & AI Workflows**

I've worked in software engineering for more than 30 years, from low-level instrument control and systems programming to backend services, cloud infrastructure, data processing, and AI-assisted development. I enjoy building tools that solve concrete problems, especially when they cross the boundary between software and scientific or historical evidence.

My public repositories include current research projects, practical applications, and preserved code from earlier in my career.

## Current projects

| Project | What it does |
| --- | --- |
| **[Ars Astronomica](https://github.com/sweisman/ars-astronomica)** · [website](https://arsastronomica.com) | A digital publishing project bringing historical Hebrew and Latin works in astronomy, cosmology, and natural philosophy into English. The repository supports a growing corpus of editions and source-linked research. |
| **[Local Level Lab](https://github.com/sweisman/local-level-lab)** · [website](https://locallevellab.com) | An open, reproducible analysis of aircraft IMU and navigation measurements, beginning with NASA Operation IceBridge data, to compare competing geometric models and their predictions. |
| **[Tychonides](https://github.com/sweisman/tychonides)** · [website](https://tychonides.com) | A source-linked catalog of historical astronomical observations, beginning with Tycho Brahe, designed for reproducible analysis and comparisons of astronomical models. |
| **[Translation Pipeline](https://github.com/sweisman/translation-pipeline)** | A public demonstration of an earlier AI-assisted workflow for reading historical scans, translating Hebrew and Latin texts, reconciling discrepancies, and producing editions. The production pipeline is more advanced and is not public. |

## Systems engineering — earlier work

| Project | What it demonstrates |
| --- | --- |
| **[cass-edi](https://github.com/sweisman/cass-edi)** · **Forth, 1991** | My earliest professional work at UC San Diego's Center for Astrophysics and Space Sciences: a substantial 32-bit Forth test-harness system for an Electron Drift Instrument. It integrates low-level hardware control, DMA acquisition, PID stepper-motor control, automated test execution, data analysis, graphics, and an interactive operator interface. The original code is preserved as a historical snapshot. |
| **[Cuttlefish](https://github.com/sweisman/cuttlefish)** · **C** | A Windows/Linux reverse-tunnel administration toolkit, with framed communication, mutual TLS, command execution, file transfer, and TCP forwarding. |
| **[Oddie](https://github.com/sweisman/oddie)** · **C** | An ODBC query daemon with a command-line and streaming request/response interface, correlation IDs, compressed results, and result hashing. |
| **[Email Blaster](https://github.com/sweisman/email-blaster)** · **Perl** | Historical high-throughput SMTP software that used Linux `epoll` system calls directly from Perl, with multiprocessing and event-driven network I/O. Preserved in its original context. |
